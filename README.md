# MIHAR

Artist website for MIHAR, hip-hop artist and speaker.

Static site: `index.html` plus `assets/`. No build step.

## Publish with GitHub Pages
1. Push these files to a GitHub repository.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. The site goes live at `https://<username>.github.io/<repo>/`.

## Edit
- Journal entries: the `<article class="entry">` blocks in `index.html`.
- Links: Spotify and Instagram URLs appear in the nav and contact sections.
